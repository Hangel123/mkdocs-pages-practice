
# API 参考

本页面展示一个简单的 Python 计算器 API 示例。

## add(a, b)

功能：计算两个数字的和。

```python
def add(a, b):
    return a + b
```

调用示例：

```python
result = add(2, 3)
print(result)  # 5
```

## multiply(a, b)

功能：计算两个数字的乘积。

```python
def multiply(a, b):
    return a * b
```

调用示例：

```python
result = multiply(3, 4)
print(result)  # 12
```
